# FlickSmith v0.5d Creative Orchestration

v0.5d adds evidence-aware coverage planning, declarative Director plans, typed creative action plans, resumable execution receipts, responsive-variant planning, and localized repair planning on top of the v0.5c generated-scene runtime.

Release gates include the full TypeScript verification suite plus `tests/integration/chatgpt-portability.test.ts` and the clean-environment smoke script. Generation remains transactional and generated imagery is converted to editable native scene structure where the configured provider/decomposition capabilities allow it.

The ChatGPT portability package does not claim that a text-only conversation can execute local binaries. Full execution requires a ChatGPT environment with process execution or a deployed authenticated FlickSmith backend.
