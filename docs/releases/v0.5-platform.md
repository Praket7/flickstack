# FlickSmith v0.5 Platform Layer

FlickSmith v0.5 layers agent-native creation, generated scene assets, professional finishing foundations, portable ChatGPT tooling, and platform infrastructure on the verified v0.4 native motion/render core.

## Completed stages

- **v0.5a Unified V3 Agent Runtime** — v3 professional motion operations are available through revision-safe agent/MCP contracts with checkpoints, receipts, locks, undo/redo, cameras, compositing, rigs, responsive variants, and render diagnostics.
- **v0.5b Generative Provider Runtime** — provider-neutral staged generation, cancellation, budgets/rights, immutable provenance, content-addressed acceptance, and OpenAI conversational image generation.
- **v0.5c Generated Scene Assets** — direct-alpha/multilayer/segmentation strategies, clean-plate/occlusion safety, depth planning, native v3 layer assembly, editable 2.5D camera motion, regeneration, QC, and Studio surface.
- **v0.5d Creative Orchestration** — declarative creative plans, evidence-first generation policy, coverage-aware Director planning, responsive variants, resumable execution primitives, localized repair planning, and MCP creative helpers.
- **v0.5e Professional Finish & Interchange** — deterministic color transforms/scopes/HDR metadata, OTIO-preserving round trip, FCPXML/EDL export, conform/relink diagnostics, audio automation/loudness/repair planning, and an isolated OpenFX host boundary.
- **v0.5f Platform** — permissioned extension SDK, review anchors/approvals, semantic render-cache keys, immutable render-worker contracts, measured-hardware benchmark gates, portable `plugin.json` + `mcp.json`, and ChatGPT/Work/Codex guidance.

## Human-crafted quality gate

Research with professional-editor and film-grade evaluation literature was converted into a release gate rather than a cosmetic prompt. FlickSmith now checks for template repetition, decorative/unmotivated motion, transition spam, mechanical pacing, generic typography, weak sound design, and insufficient brand-specific decisions. The system prefers cuts and motivated movement, keeps critical text native, treats sound as part of the edit, and uses generation to solve specific coverage gaps.

This is not an attempt to hide AI provenance. Generated assets remain traceable. The goal is for the edit to be deliberately authored rather than visibly assembled from generic AI-video conventions.

## ChatGPT portability

- `plugin.json` is the portable plugin manifest.
- `mcp.json` declares the stdio FlickSmith MCP server.
- `skills/flicksmith-create/SKILL.md` defines the creative/editorial behavior.
- `apps/mcp/src/mcp-stdio.ts` exposes the v3/generation/generated-scene tools plus creative-planning and human-craft tools without requiring the Codex UI.
- `scripts/smoke-chatgpt.sh` is the clean-environment verification gate.
- `docs/CHATGPT_WORK_CODEX.md` contains setup instructions and execution boundaries.

## Verification policy

A feature is not considered complete merely because its source exists. TypeScript typecheck/tests, clean-environment smoke checks, native Rust formatting/check/tests, and PR CI must pass before the v0.5 tree is merged to `main`.

Performance claims require at least three measured samples on a matching hardware fingerprint. The generic CI environment validates the benchmark harness but is not used to claim workstation/GPU throughput.
