# FlickSmith v0.5 CI Verification Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:verification-before-completion before claiming release readiness.

**Goal:** Verify the final v0.5 head with the workflow definition that ships in v0.5, not only the older native workflow definition currently present on `main`.

**Architecture:** PR checks validate the merge result against `main`. The v0.5 final branch also participates in the native workflow `push` trigger so the updated workflow can validate its own Rust, OpenCV, Tauri, macOS, and Windows gates before merge.

**Tech Stack:** GitHub Actions, Node 22, Rust 1.88, Cargo/Clippy/Rustfmt, Tauri 2, FFmpeg, OpenCV.

**Spec:** `docs/superpowers/plans/2026-10-10-v0.5-release-finalization.md`.

## Verification sequence

- [x] Remove the temporary self-committing Clippy diagnostic workflow and artifact.
- [x] Fix rustfmt-sensitive release assertions and the human-craft semantic assertion.
- [x] Apply Rustfmt to the radial-gradient expression.
- [x] Migrate WGPU compositor calls to the wgpu 30 API, including adapter options, optional bind-group layouts, and fallible mapped-range access.
- [x] Fix strict Clippy's manual-div-ceil finding in GPU readback sizing.
- [x] Pin Tauri CLI 2.11.5 so desktop packaging remains compatible with the workspace's Rust 1.88 toolchain.
- [x] Add `feature/flicksmith-v0.5-final` to the native workflow push branches so the updated workflow can verify itself before merge.
- [ ] Confirm `CI` passes on the final head.
- [ ] Confirm branch-native `FlickSmith v0.4 Native Verification` passes Rust format, strict Clippy, Rust tests, OpenCV tracking, macOS packaging/smoke, and Windows packaging/smoke on that same head.
- [ ] Confirm no temporary diagnostics, credentials, build outputs, or accidental artifacts are present in the final tree.
- [ ] Record the exact verified head SHA and workflow run IDs in PR #1 before merge.

## Failure policy

Every deterministic failure gets a root-cause fix. Any fix creates a new release-candidate head and invalidates earlier green evidence. Do not merge from a head that was not verified by both the JavaScript/TypeScript gate and the updated native gate.
