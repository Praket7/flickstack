# FlickSmith v0.5e Professional Finish & Interchange Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close the highest-value finishing gaps needed to deliver professional projects: verified color management/HDR, reliable interchange/conform, deeper audio automation/repair, and isolated plugin execution.

**Architecture:** Keep specialist standards at explicit boundaries instead of reimplementing entire DCC applications. Color transforms become typed render instructions shared by CPU/WGPU backends; OTIO becomes the canonical interchange bridge with targeted FCPXML/EDL support; audio automation stays in canonical project state; OpenFX runs out-of-process with a narrow permissioned protocol. Unsupported mappings remain diagnostics, not silently flattened approximations.

**Tech Stack:** TypeScript 5.8, Rust 1.88, wgpu/native CPU renderers, FFmpeg/ffprobe, OpenColorIO/ACES adapter, OTIO/FCPXML/EDL, existing audio engine, isolated process IPC, Node/Rust tests.

**Spec:** `docs/superpowers/specs/2026-10-09-flicksmith-v0.5-agent-native-creative-platform-design.md`

## Global Constraints

- Existing projects remain readable when color/plugin runtimes are unavailable.
- Preview and final render must use the same declared color intent; no hidden display LUTs.
- Unsupported interchange constructs must produce explicit diagnostics and preserve source metadata where possible.
- OpenFX execution remains disabled unless the isolated host passes capability/safety checks.
- Core editing/rendering remains possible without third-party plugins.
- No interchange or plugin import may execute embedded scripts/macros.
- `npm run verify` and relevant Rust workspace tests must pass before release.

## Review Focus

- A missing OCIO config must fail clearly instead of silently treating tagged media as correctly transformed.
- Round-tripped variable-rate/timebase timelines must preserve frame/timecode semantics.
- Relinking two files with the same basename but different duration/hash must not choose the wrong media automatically.
- Audio automation must remain deterministic across preview/final render.
- A crashed or malicious plugin process must not corrupt the project or take down the main editor process.

## Release Gate

v0.5e is complete only when color transforms are actually processed (not metadata-only), CPU/GPU color results meet parity thresholds, OTIO supports tested two-way interchange, FCPXML/EDL/conform failures are explicit, audio automation is canonical and deterministic, and OpenFX cannot crash or directly compromise the main FlickSmith process.
